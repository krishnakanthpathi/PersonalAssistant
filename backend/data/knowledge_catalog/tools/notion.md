# Notion API Integration

This tool group provides a complete interface to the Notion API, allowing automation and programmatic control over Notion workspaces. It covers user management, content search, block manipulation, page operations, database interactions, and comment handling.

### Available Tools

**User Management**
- **`API-get-user`**: Retrieve a specific user.
- **`API-get-users`**: List all users in the workspace.
- **`API-get-self`**: Retrieve your token's bot user.

**Search & Navigation**
- **`API-post-search`**: Search pages and databases by title.

**Block Operations**
- **`API-get-block-children`**: Retrieve children of a block.
- **`API-patch-block-children`**: Append new children to a block.
- **`API-retrieve-a-block`**: Retrieve a specific block.
- **`API-update-a-block`**: Update a block's content.
- **`API-delete-a-block`**: Delete a block.

**Page Operations**
- **`API-retrieve-a-page`**: Retrieve a page.
- **`API-patch-page`**: Update page properties.
- **`API-post-page`**: Create a new page.
- **`API-retrieve-a-page-property`**: Retrieve a page property item.
- **`API-move-page`**: Move a page to a new location.
- **`API-retrieve-page-markdown`**: Retrieve a page as Markdown.
- **`API-update-page-markdown`**: Update a page's content as Markdown.

**Database & Data Source Operations**
- **`API-retrieve-a-database`**: Retrieve a database.
- **`API-query-data-source`**: Query a data source.
- **`API-retrieve-a-data-source`**: Retrieve a data source.
- **`API-update-a-data-source`**: Update a data source.
- **`API-create-a-data-source`**: Create a new data source.
- **`API-list-data-source-templates`**: List templates in a data source.

**Comments**
- **`API-retrieve-a-comment`**: Retrieve comments.
- **`API-create-a-comment`**: Create a new comment.
