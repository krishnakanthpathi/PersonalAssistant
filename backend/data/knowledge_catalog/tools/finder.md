# macOS Finder & System Shortcuts

These tools interact with the macOS Finder environment and the Apple Shortcuts system, allowing for basic file system maintenance and自动化 automation workflows.

**Available Tools:**
- **`empty_trash`**: Empties the macOS Trash folder.
- **`shortcut_list`**: List Apple Shortcuts on this Mac (optional folder filter).
- **`shortcut_run`**: Run an Apple Shortcut by name (optional input/output paths). 60 s timeout.
