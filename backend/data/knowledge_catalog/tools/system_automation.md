# System Automation & Integration Toolkit

This toolkit provides extensive automation capabilities organized into several domains:

**Knowledge & MCP Integration:** `get_knowledge_document`, `update_knowledge_document`, `create_prebuilt_form`, `integrate_mcp_server` - Manage OKF documents, create dynamic forms, and integrate MCP servers.

**File System Operations:** `read_text_file`, `read_media_file`, `read_multiple_files`, `edit_file`, `move_file` - Read, edit, and manage files with various encodings and formats.

**Time & Calendar:** `get_current_time`, `get-current-time`, `list-colors`, `get-freebusy` - Time retrieval and calendar schedule management.

**Gmail Integration:** `get_profile`, `list_labels`, `create_label`, `get_attachment`, `create_filter`, `list_filters`, `get_vacation`, `update_vacation`, `manage-accounts`, delegates, forwarding, S/MIME, and more for complete email management.

**GitHub Operations:** `create_repository`, `create_issue`, `create_pull_request`, `push_files`, `get_file_contents`, `list_issues`, `merge_pull_request`, fork, branch, and commit operations.

**Docker Management:** `docker-images`, `docker-containers`, `docker-build`, `docker-compose`, `docker-run`, `docker-exec`, `docker-logs`, `docker-network`, `docker-volume`, and more for container lifecycle control.

**Memory Management (Mem0):** `add_memory`, `list_memories`, `get_memory`, `update_memory`, `delete_memory`, batch operations, and export capabilities.

**macOS System Control:** `volume_set`, `get_volume`, `list_applications`, `open_application`, `close_application`, `set_dark_mode`, `lock_screen`, `system_power`, `take_screenshot`, `say_speech`, `notify`, `prompt_user`, `clipboard_read`, `clipboard_write`, `media_control`, `safari`, `notes`, `get_system_stats`, `iphone_mirror`, `get_date_time`, `wait_ms`.

**Calculator & Math:** `calculate_expression`, `batch_calculate`, `calculate_statistics`, `matrix_operation`, `convert_units`, `convert_natural_language`, `analyze_number_theory`, session management, and history.

**Advanced Reasoning:** `sequentialthinking` - Dynamic problem-solving through structured chain-of-thought analysis with hypothesis generation and verification.
