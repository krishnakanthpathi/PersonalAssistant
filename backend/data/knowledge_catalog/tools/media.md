# YouTube Media Search, Playback & Download

This tool group provides comprehensive functionality for interacting with YouTube content. It enables users to discover, consume, and extract content from the platform.

**Available Tools:**
- **`search_youtube_videos`**: Find YouTube videos using specific search terms.
- **`get_youtube_transcript`**: Retrieve the text transcript of a specific YouTube video.
- **`download_youtube_video`**: Download a YouTube video to local storage.
- **`play_youtube_audio`**: Stream audio from a video or search query in the background via mpv.
- **`stop_youtube_audio`**: Halt any currently playing background audio stream.
