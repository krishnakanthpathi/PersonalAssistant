# Web Browsing & Search Tools

This tool group provides comprehensive search and retrieval capabilities across multiple domains:

- **`search`**: Search the web using DuckDuckGo with support for region localization and configurable result counts.
- **`fetch_content`**: Extract clean, readable text content from webpages with pagination support for long articles.
- **`search_files`**: Recursively search local directories using glob-style patterns to locate files and folders.
- **`search_repositories`**: Discover GitHub repositories matching specific criteria.
- **`search_code`**: Search for code across GitHub repositories.
- **`search_issues`**: Find issues and pull requests across GitHub repositories.
- **`search_users`**: Search for GitHub users.
- **`search_memories`**: Query stored memories based on search terms.
- **`search_memory`**: Backward-compatible alias for search_memories.
