# Gmail API — Email, Drafts, Threads & Mailbox Management

This tool group provides comprehensive access to Gmail functionality and related macOS messaging applications. It enables full programmatic control over email workflows including **Draft Management** (`create_draft`, `delete_draft`, `get_draft`, `list_drafts`, `send_draft`), **Message Operations** (`get_message`, `list_messages`, `send_message`, `delete_message`, `trash_message`, `untrash_message`, `batch_delete_messages`, `batch_modify_messages`, `modify_message`), **Thread Management** (`get_thread`, `list_threads`, `delete_thread`, `trash_thread`, `untrash_thread`, `modify_thread`), **Mailbox Monitoring** (`watch_mailbox`, `stop_mail_watch`), and **macOS Native Apps** (`mail` for Mail.app integration, `messages` for Messages.app/SMS functionality).
