# MCP Server - docker

Integrated MCP server providing tools and capabilities for docker.

### Available Tools

- **`docker-images`**: List Docker images on the host system
- **`docker-containers`**: List Docker containers on the host system
- **`docker-logs`**: Fetch logs for a specific Docker container
- **`docker-pull`**: Pull a Docker image from a registry
- **`docker-build`**: Build a Docker image from a Dockerfile
- **`docker-compose`**: Run Docker Compose commands
- **`docker-network`**: Manage Docker networks
- **`docker-volume`**: Manage Docker volumes
- **`docker-run`**: Run a Docker container with specified options
- **`docker-inspect`**: Inspect Docker objects (images, containers, networks, volumes)
- **`docker-exec`**: Execute a command in a running Docker container
- **`docker-prune`**: Remove unused Docker objects (images, containers, networks, volumes)
- **`docker-login`**: Log in to a Docker registry
- **`docker-logout`**: Log out from a Docker registry
- **`docker-bridge`**: Manage Docker bridge networks and connections
- **`docker-list`**: List all available Docker MCP tools and CLI aliases with usage examples
- **`docker-publish`**: Pubish the Image to the Docker Hub Registry
- **`docker-restart`**: Restart Docker containers with optional timeout
- **`docker-remove`**: Remove Docker containers with options
- **`docker-start`**: Start Docker containers
- **`docker-stop`**: Stop Docker containers
- **`docker-clean`**: Clean Docker system with different scopes
- **`docker-dev`**: Development environment management
- **`docker-reset`**: Reset Docker system with different levels
